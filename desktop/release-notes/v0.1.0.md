First Mac test build of the new Kiri desktop app.

What is in it:
- The new app window in the Field Notebook design: title bar, sidebar, Home, Settings (language, Learn/Expert, updates) and About.
- English, 中文 and Bilingual interface modes.
- The analysis engine runs inside the app, on your Mac only.
- Automatic updates: when a new version is ready, Kiri shows "Update ready. Restart to update".

- Projects: first-run setup, New project (with an offline gene-symbol check and all 33 TCGA cancer types), project overview, recent projects, opening .kiri files from Finder or by dragging them onto the window, autosave, "Save a version" and "Save a copy".

Not in it yet: analyses, figures and the notebook. They arrive as updates.

This build is not signed by Apple. The first time, open it with right-click → Open, or System Settings → Privacy & Security → Open Anyway.
