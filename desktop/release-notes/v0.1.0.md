First Mac test build of the new Kiri desktop app.

What is in it:
- The new app window in the Field Notebook design: title bar, sidebar, Home, Settings (language, Learn/Expert, updates) and About.
- English, 中文 and Bilingual interface modes.
- The analysis engine runs inside the app, on your Mac only.
- Automatic updates: when a new version is ready, Kiri shows "Update ready. Restart to update".
- Projects: first-run setup, New project (with an offline gene-symbol check and all 33 TCGA cancer types), project overview, recent projects, opening .kiri files from Finder or by dragging them onto the window, autosave, "Save a version" and "Save a copy".

- Survival: Kaplan–Meier curves with the number at risk, log-rank test, Cox hazard ratio (optionally adjusted for age and stage), median, quartile or optimal cutpoint (with the p-value adjusted for the search).
- Expression: tumour against normal tissue (per TCGA project), or across stages I–IV, as a box plot with every sample.
- Each result has an Explain panel (a plain reading from the numbers) and a Reliability panel (data, enough data, assumptions, multiple comparisons, effect size, stability).
- Figures: copy, save as PNG or SVG, send to the project's notebook; figure text in English or Chinese.
- The sample project carries real TCGA colorectal data for 20 genes and works offline. Other genes need a one-time cohort download.

Not in it yet: the Notebook screen, export to Word or PDF, the figure guide, other analyses (correlation, enrichment and so on), and Kiri Plus. They arrive as updates.

This build is not signed by Apple. The first time, open it with right-click → Open, or System Settings → Privacy & Security → Open Anyway.
