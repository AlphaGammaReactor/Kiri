A bigger step: the project overview, more ways to export, a second sample and a new analysis. Kiri updates itself from 0.1.2: when the banner says "Update ready. Restart to update", click it. Kiri waits if an analysis is running, and after the update it reopens the project and screen you were on.

New in 0.1.3:
- Overview: a live summary of the project with a standard panel of figures.
- Figure toolbar: a data table under each figure, PDF export, and Reproduce, which gives R and Python scripts for the same result.
- Export the notebook and the summary to Word (.docx). Chinese figure text in PDF reports uses a proper Chinese font.
- One-page summary: A4 landscape, four panels you choose from saved results, figure text at least 7 pt.
- Second sample project: TP53 in breast cancer, with a picker for the samples.
- Figure guide: pick a question and Kiri suggests the analysis and figure. It matches keywords against worked examples; there is no AI.
- Getting started checklist on Home that ticks off real steps.
- Correlation: two genes across patients, Spearman with a confidence interval, scatter plot, reliability checks, and R and Python scripts.
- Updates: a What's new note after updating, an "Updating Kiri" screen, clearer messages when an update fails, and Settings > Privacy and updates with Check now.

Not in it yet: differential expression, interactions, immune context, importing your own table, tutorials, and Kiri Plus.

This build is not signed by Apple. If macOS blocks it, open System Settings → Privacy & Security → Open Anyway.
