Second Mac test build. Kiri updates itself from 0.1.0: when the banner says "Update ready. Restart to update", click it. Kiri waits if an analysis is running.

New in 0.1.1:
- Data: the cohorts in your project, whether each is the bundled sample or a full download, download progress, and the downloaded cohorts on disk with their size. Remove a cohort to free space; it can be downloaded again.
- Activity panel (the pulse icon): analyses running and finished in this session, downloads, and the update.
- Search everything with ⌘K: genes (with alias check), analyses and notes in the project, glossary terms, and actions.
- Glossary: 24 terms in English and Chinese, searchable by pinyin, each with what it is, how to read it and a common mistake.
- Help menu: keyboard shortcuts (F1 or ?), Report a problem (you see every line; it opens a GitHub issue in your browser and nothing is sent from the app), About.
- About: references for the data your project uses, how Kiri is checked, what is new, licences and privacy.
- Settings: data folder and space used, text size and reduce motion.
- Notebook PDF export keeps each figure with its heading and numbers figures in order.

Already in 0.1.0 (its notes missed this): the Notebook, with quick notes, filters, a warning when an analysis was re-run after its figure was added, and export to PDF or a web page.

Not in it yet: Word export, the figure guide, the figure board, other analyses (correlation, enrichment and so on), importing your own data, and Kiri Plus.

This build is not signed by Apple. If macOS blocks it, open System Settings → Privacy & Security → Open Anyway.
